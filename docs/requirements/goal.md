## 目标与已确认范围

- 在现有 Haish iPhone App 的 Setting 模块内提供远程桌面入口。
- 首版为 iPhone → macOS，控制用户自己的已配对电脑，支持首次授权后的无人值守连接。
- 通过 WebRTC 实现远程桌面；核心能力为实时桌面画面、鼠标和键盘操作。
- 不替换已有 Haish 任务界面和任务协议。
- 用户明确要求只扩展当前 adapter，不修改另一仓库的桌面 App 或 agent 核心逻辑；macOS 捕获与输入能力需纳入 adapter 的实现/分发边界，最终冻结产物的真实控制能力仍需验证。
- 桌面控制必须在电脑上单独开启；开启后所有已配对设备可用，不做逐设备桌面授权。
- 手机采用触控板模式，包含单击/双击、右键、双指滚动、显式拖拽；支持横竖屏与缩放，文本输入含中文，并提供 Cmd/Ctrl/Option/Esc/Tab/方向键等快捷键。
- 首版不包含声音、剪贴板同步、文件传输和开机唤醒。
- 后续锁屏需求：手机连接已登录但正在系统锁屏的 Mac，用户手动输入系统密码解锁；不保存或自动填密码、不绕过系统锁屏。用户随后明确接受“锁屏可延后，先做解锁桌面”，因此不阻塞首版。重启首次登录/FileVault/注销不纳入本次范围。
- 快捷键切屏包括 Ctrl＋←/→ 切换桌面空间（Spaces）/全屏应用，以及 Cmd＋Tab 切换应用；按 macOS 当前系统快捷键设置工作，不修改系统设置，不指物理显示器切换。
- 网络采用 WebRTC 直连优先＋TURN 兜底；本轮不部署中继。交付自托管 TURN 配置与部署文档；鉴权后发放短期凭据，不在手机内放永久密钥，不提供匿名中继；未配置 TURN 时明确提示仅能尝试直连、不保证跨网连接。
- adapter 提供仅限本机访问的管理页，默认关闭远程桌面；开启状态持久化，关闭立即断开会话。
- 首版只支持主显示器，分辨率变化自动适配，不做切换或多屏拼接。
- 首版运行前提：Mac 开机、唤醒、已登录且未锁屏，adapter 运行；休眠、系统锁屏或 adapter 退出终止控制，恢复后手动连接。锁屏电脑的新建连接/解锁属于后续需求，不在首版宣称支持。
- 手机离开桌面页/切后台/锁屏结束会话，回前台手动重连；仅前台短暂断网自动重试最多 30 秒，停止输入并释放按键/鼠标，超时明确提示失败并提供重连。同一 Mac 仅一台手机控制，后来连接提示忙碌不抢占。不新增常驻服务或防休眠。
- 开关关闭、设备被撤销/退出配对、系统权限失效时，正在进行的会话停止捕获和输入，旧连接不能继续控制。不得把“只对新请求检查 token”视作满足会话撤销要求。
- 首版必须支持用户当前 Apple Silicon Mac 的 macOS 14.8.9，不要求升级至 macOS 15。14.8.9 为最低目标版本，后续新版按实际验证记录，不声称已测全版本；更早 macOS 与 Intel 暂不支持。iPhone 保持现有 iOS 15 最低配置，性能以真机记录为准，不保证所有旧机型；依赖若不能兼容目标系统，需报告重新决策，不得自行提高最低版本。
- 澄清时通过只读 `sw_vers`/`uname -m` 核实本机 macOS 14.8.9、arm64。CI 的 macOS 15 runner 不是产物运行下限；后续必须核查依赖与编译部署目标并测试冻结产物在 14.8.9 上运行。

## 性能目标（用户已接受，尚未验证）

普通桌面办公/开发，最高 1080p、目标 30fps；差网络自适应降画质/帧率，不承诺游戏级体验。RTT≤100ms、可用带宽≥10Mbps、丢包≤1% 的测试条件下连续使用 10 分钟，首次画面≤10秒，操作至画面反馈 P95≤300ms，直连与 TURN 分别测试。

## 场景与验收标准

| 场景 | 验收结果 |
| --- | --- |
| 从 Setting 进入 | 提供明确远程桌面入口与连接/结束操作；只控制当前已配对电脑，不新增多电脑目录。退出返回 Setting，原任务状态不丢失。 |
| 初次启用 | 默认关闭；仅本机管理页能开启/关闭。未配对设备不可连接；已配对手机不能远程给自己开启此权限。本机管理操作不能经公网隧道或跨站请求绕过本机限制。 |
| macOS 系统权限未授予 | 明确区分屏幕录制、辅助功能权限缺失，提供系统设置指引及重试；权限不齐时不建立可控制会话，不反复弹无意义授权提示。授权主体/权限是否稳定随产物升级保留需验证。 |
| 正常连接 | 电脑已解锁、授权开启且权限齐全时，看到主显示器实时画面；鼠标移动、单击、双击、右键、双指滚动和显式拖拽均能作用于普通应用。 |
| 手机视图 | 横竖屏均可适配画面，支持缩放查看；缩放/旋转/桌面分辨率变化后鼠标定位仍正确。 |
| 键盘 | 中文/英文文本可输入普通编辑器；Cmd/Ctrl/Option/Esc/Tab/方向键可用，组合键正确按下/释放，不产生残留修饰键。 |
| 快捷键切屏 | 配置有多个 Spaces/全屏应用时，Ctrl＋←/→ 切换后收到新的主显示器画面；Cmd＋Tab 能切换应用；使用系统原有配置，不模拟物理多屏切换。 |
| 直连与 TURN | 同网及蜂窝网→家庭网场景能尝试直连；受限网络/测试强制中继时能走配置好的 TURN，仍可观看与输入。短期凭据只向已鉴权设备发放；日志不含凭据/桌面内容/输入文本。 |
| 缺失/故障 TURN | 无配置提示仅尝试直连；直连失败或 TURN 不可用时说明原因及重试入口，不永远停在连接中。无 TURN 不能声称已通过跨网兜底验收。 |
| 断网与并发 | 前台短断网重试最多 30 秒；输入停止且释放已按状态，恢复不得重放断线时旧操作。第二台设备连接提示忙碌；前一会话结束/超时清理后可以重新连接。 |
| 退出/授权撤销 | 手机后台/离开页面/锁屏、Mac 休眠/锁屏、adapter 退出、撤销设备或关闭开关后，控制立即失效，资源释放；恢复前台不自动恢复远程输入。 |
| 首版锁屏边界 | 已锁屏电脑不宣称支持连接解锁，给出当前不支持状态；后续锁屏连接需另行技术验证与审批。 |
| 既有能力回归 | 已有任务流、审批、继续输入、设备配对/撤销不退化；结束远程桌面不停止电脑上的 Haish 任务。 |
| 性能 | 在上述网络条件下，直连和 TURN 各连续使用 10 分钟，记录首次画面时间、输入至画面反馈 P95、帧率/分辨率与测试机型系统版本；使用两端时间可关联的录像或可复现测量方法，不用网络 RTT 冒充完整交互时延。 |

## 边界与假设

- 只在用户拥有且明确授权的电脑上控制，不包含他人临时协助。
- 新增能力不能仅靠手机端 WebRTC 完成；当前电脑端实现已包含捕获桌面及执行输入的能力，真实普通应用输入与最终产物仍需验收。
- 公网基础设施与发布需另行明确授权；本次文档维护不进行部署、购买、push、发布或其他外部写入，不能把提供测试建议视为授权。另一桌面仓库不在实现范围。
- 保持既有 IPA/adapter 的 GitHub Actions 发布约定。若原生组件导致产物结构或桌面端消费契约必须改变，先报告阻碍并获得新决策，不把未经批准的边界扩展当作既定方案。
- 产品需求不把具体视频编码、WebRTC 库、端口或原生桥接方案作为验收结果；当前实现方案另见实现文档。必须验证真实 iPhone WebView 与冻结 adapter 产物，而不仅验证本地浏览器/源码。
